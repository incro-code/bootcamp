Method

Three phases. Variable duration. The structure is fixed — the time allocated to each phase scales with your team's size, starting AI maturity, and the complexity of the PoC target.

Phase 01
Map
½ day – 1 day

We map your team's recurring workflows against a finance-specific AI readiness matrix. The output is a prioritised list of use cases — with a clear decision on which PoC to build, and which workflows should not use AI unsupervised.

  • Workflow-AI Matrix across your finance function
  • Data sources audit — what exists, what's accessible, what's clean
  • PoC target selected and scoped
  • Governance guardrails agreed
You leave with
Sprint brief, prioritised agent backlog, clear guardrails
Phase 02
Build
1 day – 3 days

We build the PoC agent live, in your environment, on your real data. Your team builds alongside us — not watching. We use Claude Cowork for non-technical participants and Claude Code where deeper integration is needed. The agent runs before this phase ends.

  • Finance context layer — COA, KPI definitions, reporting logic
  • Claude accounts configured for finance-specific tasks
  • Agent built and deployed on your data
  • Iteration loops until output is production-ready
You leave with
A deployed, working agent running on your actual data
Phase 03
Embed
½ day – 1 day

We hand over everything — documentation, prompt library, knowledge base — and run a structured session to make sure the team can operate, extend, and maintain the agent independently. We also set the data architecture direction for moving from Copilot mode to autonomous operation.

  • Agent fine-tuned based on team feedback
  • Full prompt library and documentation handover
  • Data architecture roadmap for autonomous operation
  • Next agents prioritised and scoped
You leave with
Docs, knowledge library, agent roadmap, architecture brief
Note

Duration scales to your team. A CFO and two analysts can complete all three phases in 2 days. A finance function of 10+ typically runs the full 5 days. We agree the timeline on the discovery call — before we arrive.
